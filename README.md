# 전략 검증 보드 (kr-strategy-board)

한국 시장 매매·배분 전략 **164개**를 하나의 엔진에 올려, **매매비용·세금·한국시장 제도·다중검정**까지 반영해 검증한 개인 기록입니다.

**보드 → https://hsh2578.github.io/kr-strategy-board/**

> 투자 권유가 아닙니다. 전부 백테스트 결과이며 실계좌 성과가 아닙니다.

---

## 왜 만들었나

전략 아이디어는 쉽게 늘어나는데, **어느 것이 비용을 내고도 남는지**는 따로 재보지 않으면 알 수 없었습니다.
그래서 아이디어를 모으는 대신 **같은 조건에서 전부 돌려 떨어뜨리는 쪽**을 만들었습니다.

## 검증 설계

| 항목 | 내용 |
|---|---|
| 대상 | KOSPI·KOSDAQ 시가총액 1,000억원 이상 보통주 (우선주·스팩·리츠·외국주권 제외) + ETF 48종 |
| 기간 | 원천 2010-01 ~ 2026-09 (4,364 영업일) · 지표 워밍업 1년 후 **2011-01-01**부터 |
| 구간 분리 | **IS 2011~2019 / OOS 2020~ / TO24** (2025~26 급등장 제외) |
| 엔진 | vectorbt (`Portfolio.from_signals` / `from_orders`), 신호는 numba |
| 성과지표 | CAGR · Vol · Sharpe · Sortino · MDD · Calmar · Exposure · Trades · WinRate · Payoff · PF · AvgTrade · AvgHoldDays · Turnover — 4구간 × 15지표 |

### 비용을 실제로 넣었습니다

- 편도 수수료 **0.015%**
- **연도별 거래세 테이블** (2010년 0.30% → 2026년 0.20%)
- 시가총액 구간별 슬리피지 편도 **0.1% / 0.2% / 0.5%**, ETF 0.05%
- 해외·채권·금·달러 ETF 매매차익 **15.4%** 과세 (연 1회 차감)
- **비용 2배 시나리오 전수 재실행** + 슬리피지 0 결과셋 별도 보관

### 한국시장 제도를 반영했습니다

- 상한가 출발·상한가 마감 **매수 차단** (가격제한폭 2015-06-15 ±15% → ±30%)
- 거래정지 구간 무체결, 청산 연기
- **상장폐지 강제청산** — 정리매매 197건의 중앙값 **−94.2%** 헤어컷 적용
- 손절 기준가는 실체결가, 손절 체결에도 슬리피지 부과

### 우연을 걸러냈습니다

- **Deflated Sharpe Ratio** (Bailey & López de Prado, 2014)
- CAPM 알파·베타와 **알파 t값** (2011~2024, KODEX200 기준)
- **랜덤 진입 대조군**
- CSCV **PBO** (S=16)

## 결과 — 대부분 떨어졌습니다

| 판정 | 수 |
|---|---|
| 비용 반영 후 전체기간 CAGR 음수 | **75 / 164** |
| 비용 2배에서 OOS 샤프 ≤ 0 | **84 / 164** |
| 랜덤 진입 대조군에 패배 | 26 / 50 |
| **DSR 95% 초과** | **0개** (체결 불가·수급 결함 8종 제외한 156개 기준) |

> 164개를 시험하면 16년 동안 실력 없이도 초과 샤프 약 0.68까지 우연히 나옵니다.
> 그 보정을 거치면 **기준을 넘는 전략은 없었습니다.**

그래서 통계적 유의성 대신 다른 문을 세워 **네 개**를 남겼습니다 (판정 구간 2011-01-01 ~ 2024-12-31).

문은 하나가 아닙니다. 앞에서 떨어지면 뒤는 보지 않습니다.

1. 2011~2024 연수익 > 0
2. 앞 구간(IS) 연수익 > 0
3. **비용 2배에서 OOS 샤프 > 0**
4. 단일 지수 보유(`H*`)와 체결 불가·수급 결함 8종 제외
5. 1차 자료 대조에서 퀀트 판정이 '문제'인 9종 제외 — 사후 구간 선택, 국면 라벨 지연에 성과가 무너짐 등
6. 남은 것 중 **초과 샤프 ≥ 0.5 이고 알파 t > 2**

6번만 떼어 적용하면 여섯 개가 통과합니다. 그 둘은 서로 다른 문에서 떨어졌습니다 —
`H05 미국나스닥100 보유`는 4번(단일 지수를 그냥 들고 있는 것)에서, `LT27 저PER+저PBR 20 + 할로윈`은
5번(여름에 채권으로 옮기는 구간을 열두 개 후보에서 사후에 고른 것)에서 떨어집니다. 남은 것이 네 개입니다.
샤프는 전부 KODEX 단기채권 대비 초과수익 기준입니다.

| ID | 전략 | CAGR | 초과 샤프 | 알파 t | MDD |
|---|---|---|---|---|---|
| LT32 | 연말 배당 교대 (9월말 고배당30 → 12월말 청산 → 코스닥 낙폭과대30 → 1/15 청산) | 9.13% | 0.724 | 2.64 | −18.5% |
| AA09 | HAA-Simple (미국 TIP·SPY 모멘텀) | 9.54% | 0.671 | 2.46 | −16.8% |
| AA17 | 코스피·나스닥100·달러 1:1:1 분기 리밸런싱 | 8.03% | 0.656 | 2.89 | −21.9% |
| AA10 | LAA 한국판 | 6.18% | 0.512 | 2.28 | −19.1% |

같은 기간 KODEX200은 연 4.7% · 초과 샤프 0.23입니다.
**넷 다 종목을 고르는 전략이 아니라 자산을 옮기는 전략**이라는 점이 이 검증에서 얻은 결론입니다.

### 부가 검증도 실패로 끝났습니다

| 시도 | 결과 |
|---|---|
| 매달 상위 5개 전략 자동선택 | CAGR 4.99% · 초과 샤프 0.417 → **KODEX200(0.591)에 패배** |
| 국면 판단 4종 | 전부 '국면 없음'보다 샤프 낮음. Holm 보정 p = 1.0 |

| 오버레이 9변형 (변동성 타겟·모멘텀 필터·국면 노출) | 기준 포트폴리오의 OOS 샤프 0.80을 **어느 변형도 넘지 못함** |

## 한계 — 스스로 적어 둡니다

- **수급 전략 6종은 순위에서 제외**했습니다. 수급 데이터에 생존편향과 수집 차단이 있어 결과를 신뢰하지 않습니다.
- 통과 전략 12개 중 **1차 자료를 확인하지 못한 것이 5건**, 원문과 다르게 구현된 것이 2건입니다. "출처대로 구현했다"고 말할 수 없습니다.
- PBO는 계산은 하되 **파일로 저장하지 않아** 값을 재확인할 수 없습니다.
- 분봉 전략(ORB·VWAP·동시호가), 야간선물, 컨센서스 기반 이익 모멘텀은 **데이터가 없어 제외**했습니다.

## 구성

```
index.html                 보드 (단일 파일)
robots.txt                 검색 색인 차단
backtest/
  engine.py                체결 엔진 — 미래참조 차단·가격제한폭·거래정지·상장폐지 헤어컷
  costs.py                 수수료·연도별 거래세·시총 구간별 슬리피지
  strategies*.py           전략 정의 164개 (기술적·중장기 팩터·자산배분·재무)
  regimes.py               국면 판정 4종
  overlay.py               오버레이 9변형 (변동성 타겟·모멘텀 필터·국면 노출)
  meta.py                  매달 상위 전략 자동선택 (메타 전략)
  report.py                DSR·CAPM 알파·랜덤 대조군·리포트
  site_build.py            등급 판정 + 보드 HTML 생성
  kr_data.py collect*.py   KRX·수급·매크로 수집
  dart_*.py                DART 재무 수집·패널화
  test_*.py                엔진 규칙 회귀 테스트
  results/*.csv            164전략 전수 결과 (ranking·metrics·alpha_beta·등급표)
```

원천 시세·재무 패널(약 1.5GB)과 일별 수익률 parquet은 용량 때문에 올리지 않았습니다.
`results/` 의 CSV로 위 표의 모든 수치를 재확인할 수 있습니다.
